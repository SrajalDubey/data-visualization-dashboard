# data-visualization-dashboard
Business performance dashboard built using IBM Cognos

Objective:
To build an interactive dashboard for business performance analysis using real-world sales and recall data.

Tools Used:
- IBM Cognos Analytics
- Excel
- Data Visualization Techniques

Key Features:
- KPI Metrics (Profit, Quantity Sold)
- Sales Analysis by Month
- Recall Analysis by Vehicle Model
- Customer Sentiment Overview

Key Insights:
- Identified top-performing months based on profit and sales
- Analyzed recall distribution across models
- Compared customer sentiment trends

Skills Demonstrated:
- Data Visualization
- Dashboard Design
- Business Insight Generation
